# Text Wireframe (ASCII Layout) - Lab 04

เอกสารนี้รวบรวมแบบร่างหน้าจอ ASCII Layout จำนวน 3 หน้าจอสำหรับระบบ **SWE Inventory Management System** โดยออกแบบตามหลัก Usability และ Accessibility (WCAG 2.1 AA) เพื่อตอบโจทย์ผู้ใช้กลุ่มพนักงานคลังสินค้าที่มีทักษะเทคโนโลยีระดับเริ่มต้น (2/5)

---

## 1. หน้า Login (เข้าสู่ระบบ)

```text
+-----------------------------------------------------------------------+
|  [Logo] SWE INVENTORY SYSTEM                                          |
+-----------------------------------------------------------------------+
|                                                                       |
|                     +-------------------------------+                 |
|                     |      เข้าสู่ระบบจัดการคลัง      |                 |
|                     |                               |                 |
|                     |  ชื่อผู้ใช้งาน (Username) *    |                 |
|                     |  +-------------------------+  |                 |
|                     |  | sommai_w01              |  |                 |
|                     |  +-------------------------+  |                 |
|                     |  [!] กรุณากรอกชื่อผู้ใช้งาน    | (Error State)   |
|                     |                               |                 |
|                     |  รหัสผ่าน (Password) *         |                 |
|                     |  +-------------------------+  |                 |
|                     |  | **********              |  |                 |
|                     |  +-------------------------+  |                 |
|                     |  [!] รหัสผ่านต้องมีอย่างน้อย 8 ตัวอักษร          |
|                     |                               |                 |
|                     |  [ ] จดจำชื่อผู้ใช้ในเครื่องนี้ |                 |
|                     |                               |                 |
|                     |  +-------------------------+  |                 |
|                     |  |  [ เข้าสู่ระบบ (Login) ]  |  | (Primary Button)|
|                     |  +-------------------------+  |                 |
|                     |                               |                 |
|                     |  ลืมรหัสผ่าน? ติดต่อ Admin      |                 |
|                     +-------------------------------+                 |
|                                                                       |
+-----------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility (Login):
- **Usability:** ฟอร์มจัดกึ่งกลางสายตา ลำดับ Tab จากบนลงล่างอย่างเป็นธรรมชาติ ปุ่มเข้าสู่ระบบมีขนาดใหญ่และใช้สี Primary ชัดเจน
- **Accessibility:** มี Label ถาวรด้านบนช่องกรอกทุกช่อง มีเครื่องหมาย `*` สำหรับช่องบังคับ และ Error message แสดงข้อความชี้แนะการแก้ไขชัดเจน ไม่พึ่งพาเพียงการเปลี่ยนสีขอบแดงอย่างเดียว

### คำอธิบาย Usability & Accessibility (Dashboard):
- **Usability:** แสดงภาพรวมและจุดวิกฤต (Low Stock Alert) ทันทีบนหน้าแรก แยกตัวเลขสินค้าจริงและสินค้าดิจิทัลชัดเจน พนักงานไม่ต้องเสียเวลาคำนวณเอง
- **Accessibility:** มีแถบแจ้งเตือน Warning สี `#B45309` พร้อมสัญลักษณ์ `(!)` และข้อความระบุสถานะชัดเจน ไม่ใช้เพียงโค้ดสีในการสื่อสาร

## 3. หน้า Add Product (เพิ่มสินค้าใหม่เข้าระบบ)

```text
+-----------------------------------------------------------------------+
| SWE INVENTORY | [แดชบอร์ด] | [รายการสินค้า] | [เพิ่มสินค้า]* | (User: สมหมาย) |
+-----------------------------------------------------------------------+
|                                                                       |
|  [V] สำเร็จ: บันทึกข้อมูลสินค้า "สมุดบันทึกดิจิทัล 2026" เรียบร้อยแล้ว (Success) |
|                                                                       |
|  แบบฟอร์มเพิ่มสินค้าใหม่ (Add New Product)                            |
|  -------------------------------------------------------------------  |
|                                                                       |
|  ชนิดสินค้า (Product Type) *                                          |
|  (o) สินค้าที่จับต้องได้ (Physical Goods) - มีการตัดสต็อกเมื่อขาย     |
|  ( ) สินค้าดิจิทัล (Digital Goods / E-Book / File) - ไม่มีการตัดสต็อก |
|                                                                       |
|  ชื่อสินค้า (Product Name) *                                          |
|  +-----------------------------------------------------------------+  |
|  | สมุดโน้ตปกแข็ง A5 ตารางกริด                                     |  |
|  +-----------------------------------------------------------------+  |
|  [!] ชื่อสินค้าต้องไม่ว่างเปล่า และต้องไม่ซ้ำกับสินค้าในระบบ          |
|                                                                       |
|  รหัสสินค้า (SKU) *               หมวดหมู่ (Category) *               |
|  +-------------------------------+ +-------------------------------+  |
|  | SKU-STAT-009                  | | เครื่องเขียนและอุปกรณ์สำนักงาน v|  |
|  +-------------------------------+ +-------------------------------+  |
|                                                                       |
|  ราคาขายต่อหน่วย (บาท) *          จำนวนสต็อกเริ่มต้น (ชิ้น) *          |
|  +-------------------------------+ +-------------------------------+  |
|  | 150.00                        | | 50                            |  |
|  +-------------------------------+ +-------------------------------+  |
|  [!] ราคาต้องมากกว่า 0 บาท        [!] สินค้าดิจิทัลช่องนี้จะถูกปิดอัตโนมัติ|
|                                                                       |
|  ลิงก์ไฟล์สำหรับดาวน์โหลด (กรณีสินค้าดิจิทัลเท่านั้น)                  |
|  +-----------------------------------------------------------------+  |
|  | https://storage.rmuti.ac.th/download/ebook-01.pdf               |  |
|  +-----------------------------------------------------------------+  |
|                                                                       |
|  -------------------------------------------------------------------  |
|                                  [ ยกเลิก ]      [ บันทึกสินค้า * ]   |
|                                (Secondary)           (Primary)        |
+-----------------------------------------------------------------------+
```

### คำอธิบาย Usability & Accessibility (Add Product):
- **Usability:** 
  1. มี Radio button เลือกชนิดสินค้าตั้งแต่เริ่มต้น เพื่อปรับเปลี่ยนช่องกรอกให้สอดคล้องกับประเภทสินค้า (ถ้าเลือกดิจิทัลจะ disable ช่องสต็อกอัตโนมัติ)
  2. จัดวางปุ่มบันทึก (Primary) ไว้ทางขวาล่าง และปุ่มยกเลิก (Secondary) อยู่ทางซ้าย แยกสีและระยะห่างชัดเจน ป้องกันการคลิกผิด
  3. แสดง Success Message ชัดเจนหลังบันทึก แก้จุดสะดุดใน Journey Map
- **Accessibility:**
  1. ทุกช่องมี Label กำกับอยู่ข้างบน ไม่ใช้ Placeholder แทน Label
  2. ช่องบังคับกรอกมีเครื่องหมายดอกจัน `*`
  3. Error Message อธิบายวิธีแก้ไขโดยละเอียด ไม่ใช้เพียงคำว่า "เกิดข้อผิดพลาด"
  4. รองรับการกดแป้น Tab ต่อเนื่องจากซ้ายไปขวา บนลงล่าง
